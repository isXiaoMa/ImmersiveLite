基本设置

源语言建议保持"自动检测"。切换服务后，已翻译页面会自动重新翻译。

交互设置

悬浮球：页面右侧的"译"字圆球，点击翻译/还原，可上下拖动。 划词翻译：选中一段文字后自动弹出译文卡片。

免费智能翻译（推荐）

自动降级链：优先微软翻译（批量快），失败自动切换谷歌翻译，全部失败才提示错误。 无需任何配置，开箱即用。

谷歌翻译（免费）

使用谷歌公共接口，无需任何配置，开箱即用。适合日常网页阅读。

百度翻译

前往 百度翻译开放平台 注册成为开发者并开通"通用文本翻译"即可免费获得（标准版每月有免费额度）。

大模型翻译（OpenAI 兼容接口）

每个配置会作为独立选项出现在服务下拉中（如 GPT-5.2、DeepSeek）。 API 地址填写到 /v1 即可，例如 DeepSeek：https://api.deepseek.com/v1

Coze（扣子）使用原生协议：API 地址填 https://api.coze.cn（海外填 com）， API Key 填个人访问令牌 PAT，"模型名"栏填发布到 API 的 Bot ID； 并建议在 Coze 平台为 Bot 设置"严格按指令输出 JSON 数组"的人设。

豆包（火山方舟）推荐直连，无需经过 Coze：到火山引擎控制台开通"火山方舟"并 获取 API Key， 模型名填 Model ID（如 doubao-seed-2-1-pro-260628）或推理接入点 ID（ep- 开头）； 订阅了 Agent Plan 套餐的用户把地址改为 https://ark.cn-beijing.volces.com/api/plan/v3。
